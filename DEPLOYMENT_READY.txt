================================================================================
TROUBLESHOOTING
================================================================================

If deployment fails:
  1. Check build log in Render dashboard
  2. Look for Python version (should be 3.11.9)
  3. Verify pip install succeeded
  4. Check for import errors

If API returns 500 error:
  1. Check Render logs for full error
  2. Verify video file is valid MP4/AVI
  3. Check available disk space
  4. Verify database is writable

If service won't start:
  1. Check that gunicorn is in requirements.txt
  2. Verify app.py is in repository root
  3. Check render.yaml syntax (YAML valid)
  4. Ensure startCommand references $PORT variable
